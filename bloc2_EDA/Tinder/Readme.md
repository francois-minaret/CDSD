# ❤️ Tinder – Analyse Speed Dating & Exploration des Facteurs d’Attraction

Ce projet analyse un ensemble de données issu d’expériences de speed dating organisées entre 2002 et 2004. L’objectif est de comprendre ce qui incite deux personnes à se revoir après un premier rendez-vous de 4 minutes.

Les données incluent :
- des caractéristiques démographiques,
- des auto-évaluations,
- des préférences en matière de partenaire,
- des évaluations mutuelles (attractivité, humour, intelligence, etc.),
- le souhait d’un second rendez-vous.

## 🧠 Objectif du projet

L’objectif est de déterminer les facteurs qui influencent la probabilité d’un second rendez-vous, à travers :

- des statistiques descriptives
- des visualisations
- des analyses comparatives entre hommes et femmes
- l’étude des facteurs subjectifs (attractivité, humour…) et objectifs (origine, âge…)

## 🛠️ Technologies utilisées

- **Python** : Pandas, Requests, JSON
- **Plotly, Matplotlib, Seaborn** : visualisation cartographique

Le notebook contient :

- chargement des données
- nettoyage de variables
- analyses statistiques
- visualisations interprétées
